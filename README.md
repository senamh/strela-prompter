# Strela Суфлёр

Откройте http://127.0.0.1:8765, пока запущен локальный сервер. Для повторного запуска на macOS откройте «Запустить.command». Требуется Python 3.

Вставьте текст, настройте размер шрифта и нажмите «Начать чтение». Прокрутка автоматически следует за распознанной речью. Рекомендуются Chrome или Edge. Выберите язык и разрешите микрофон. Браузерное распознавание может требовать интернет и передачу аудио поставщику браузера. Подписка и ключ API не нужны.

Непрочитанные слова белые на чёрном фоне; все произнесённые слова тёмно-серые. Следующее слово выделено прозрачным красным прямоугольником. Доступны пауза, возврат к началу, полный экран, зеркальное отображение и импорт TXT. Текст и настройки сохраняются в текущем браузере. Сам интерфейс помещается в окно; текст прокручивается внутри области чтения.

Сопоставление фраз и интерфейс проверены. Распознавание живого голоса не проверено.

## Изменение кода

После изменения `app.js` или `matcher.mjs` выполните `node build.mjs`, чтобы обновить `bundle.js`. Для сборки требуется Node.js; для обычного чтения он не нужен.
